# Datasets

This section lists datasets and benchmarks relevant to **Single-LLM Versus Multi-Agent Debate Systems for Scientific Hypothesis Generation**. The datasets support different aspects of the research, including hypothesis generation, hypothesis evaluation, scientific-literature retrieval, and evidence gathering.

## 1. ResearchBench

**Source:** Liu et al. / ResearchBench project

**Description:**  
ResearchBench is a benchmark designed to evaluate large language models on scientific discovery. It contains three major tasks: inspiration retrieval, hypothesis composition, and hypothesis ranking. The current release contains 1,369 paper records, 1,367 retrieval tasks, 1,367 hypothesis-generation tasks, and 1,323 hypothesis-ranking tasks. It covers scientific disciplines including astronomy, biology, chemistry, physics, mathematics, and environmental science.

**Application to this research:**  
ResearchBench is directly relevant to this project because it provides tasks for generating and ranking scientific hypotheses. It can be used to compare the quality of hypotheses produced by a single LLM against hypotheses produced through multi-agent debate or collaboration.

**Link:**  
[ResearchBench Dataset](https://huggingface.co/datasets/ankilok/ResearchBench)

[ResearchBench GitHub Repository](https://github.com/ankitala/ResearchBench)

## 2. HypoBench

**Source:** Chicago Human+AI / University of Chicago

**Description:**  
HypoBench is a benchmark specifically designed to evaluate the hypothesis-generation capabilities of AI systems and large language models. It combines real-world and synthetic datasets across multiple domains and provides controlled settings for evaluating the quality of generated hypotheses. The benchmark includes 7 real-world tasks and 5 synthetic tasks, covering 194 distinct datasets.

**Application to this research:**  
HypoBench can be used to evaluate and compare hypotheses generated by different system architectures. In particular, the same dataset and task can be given to a single LLM and a multi-agent debate system, allowing their hypotheses to be compared using measures such as explanatory power, generalizability, novelty, and ground-truth hypothesis discovery.

**Link:**  
[HypoBench](https://chicagohai.github.io/HypoBench/)

[HypoBench Datasets on GitHub](https://github.com/ChicagoHAI/HypoBench-datasets)

## 3. S2ORC — Semantic Scholar Open Research Corpus

**Source:** Allen Institute for AI / Semantic Scholar

**Description:**  
S2ORC is a large-scale corpus of scientific papers designed for natural language processing and scientific text-mining research. It provides scientific-paper metadata, abstracts, bibliographic references, and machine-readable scientific text. The dataset is designed to support research involving large-scale analysis of scientific literature.

**Application to this research:**  
S2ORC can provide the scientific literature used by an LLM or multi-agent system when generating hypotheses. For example, papers can be retrieved as evidence or sources of inspiration before hypothesis generation. This makes it useful for testing whether multi-agent debate produces better hypotheses when agents have access to the same scientific literature as a single LLM.

**Link:**  
[S2ORC GitHub Repository](https://github.com/allenai/s2orc)

[Semantic Scholar Dataset Information](https://www.semanticscholar.org/product/api)

## 4. OpenAlex

**Source:** OpenAlex

**Description:**  
OpenAlex is an open index of the global research system. It contains scholarly works together with information about authors, institutions, sources, topics, publishers, funders, and citations. Its works collection includes journal articles, conference papers, books, datasets, dissertations, preprints, and other scholarly documents.

**Application to this research:**  
OpenAlex can be used as a large-scale source for finding and retrieving scientific literature relevant to a research question. A single-LLM system and a multi-agent debate system can be given access to the same OpenAlex-derived literature and compared on their ability to synthesize evidence and generate scientifically useful hypotheses.

**Link:**  
[OpenAlex](https://openalex.org/)

[OpenAlex Data Documentation](https://help.openalex.org/data/)

[OpenAlex Dataset on AWS](https://registry.opendata.aws/openalex/)

## Dataset Selection Summary

| Dataset | Primary Purpose | Relevance to Research |
|---|---|---|
| **ResearchBench** | Scientific discovery and hypothesis generation | Direct benchmark for comparing hypothesis-generation systems |
| **HypoBench** | Hypothesis-generation evaluation | Direct evaluation of hypothesis quality and discovery |
| **S2ORC** | Scientific literature corpus | Provides scientific literature for evidence retrieval and hypothesis generation |
| **OpenAlex** | Scholarly knowledge graph and literature index | Provides large-scale scientific literature and citation information |

## Overall Application

These datasets support complementary parts of the research problem:

- **ResearchBench** and **HypoBench** can be used to evaluate the quality of generated hypotheses.
- **S2ORC** and **OpenAlex** can provide scientific literature and evidence used during hypothesis generation.
- The same datasets and information sources can be supplied to both a **single-LLM system** and a **multi-agent debate system**, enabling a controlled comparison of their hypothesis-generation performance.
