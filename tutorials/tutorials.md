## Tutorials / Learning Resources

The following authoritative learning resources provide practical guidance on technologies and concepts relevant to **Single-LLM Versus Multi-Agent Debate Systems for Scientific Hypothesis Generation**.

### 1. LangChain — Agents

**Source:** LangChain Documentation

**Purpose:**  
Provides a practical introduction to building LLM-powered agents that can use tools and iteratively perform tasks. This is useful for understanding the construction of single-agent and agentic research workflows.

[LangChain Agents Documentation](https://docs.langchain.com/oss/python/langchain/agents)

---

### 2. Microsoft AutoGen — User Guide

**Source:** Microsoft

**Purpose:**  
Provides documentation and examples for building AI agents and multi-agent applications. It is particularly useful for learning how multiple agents can communicate and cooperate on complex tasks.

[AutoGen Documentation](https://microsoft.github.io/autogen/)

---

### 3. LlamaIndex — Introduction to RAG

**Source:** LlamaIndex Documentation

**Purpose:**  
Explains Retrieval-Augmented Generation (RAG), including how external documents can be indexed and retrieved to provide relevant context to an LLM. This is useful for building systems that generate hypotheses from scientific literature.

[LlamaIndex RAG Guide](https://docs.llamaindex.ai/en/stable/understanding/rag/)

---

### 4. Hugging Face LLM Course

**Source:** Hugging Face

**Purpose:**  
A comprehensive course covering transformer models, large language models, model inference, fine-tuning, datasets, and related NLP techniques. It provides the foundational knowledge required to work with LLMs used in hypothesis-generation systems.

[Hugging Face LLM Course](https://huggingface.co/learn/llm-course)

---

### 5. DSPy Documentation

**Source:** Stanford NLP

**Purpose:**  
Introduces a programming framework for building and optimizing LLM-based systems. It is useful for learning how modular language-model pipelines can be designed and optimized for tasks such as generation, evaluation, and reasoning.

[DSPy Documentation](https://dspy.ai/)

---

### Relevance to This Research

These resources cover the main technical components required for developing and studying the systems in this project:

- **LangChain** — LLM agents and tool-based workflows
- **AutoGen** — multi-agent systems and agent communication
- **LlamaIndex** — scientific-literature retrieval and RAG
- **Hugging Face** — transformer models and LLM fundamentals
- **DSPy** — modular and optimized LLM pipelines
